Toybox Retro Sprite Atlas

atlas.png contains 123 original, safe 32x32 pixel sprites used by the ambient
encounter system. The production theme ships only the consolidated runtime
atlas; individual PixelLab source frames are intentionally excluded.

The sprites are Famicom-era arcade homages and do not reproduce game logos or
character artwork. Horror masks, weapons, mines, claws, ghosts, and bats are
not included in the runtime atlas.
